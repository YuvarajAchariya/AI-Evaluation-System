3.An IP Address (Internet Protocol Address) is a unique identification number assigned to every device connected to a network. It helps devices find and communicate with each other on the internet. Just like a home address helps identify a location, an IP address helps identify a device. IP addresses are usually written in numbers separated by dots, such as 192.168.0.1. There are two main types of IP addresses: IPv4 and IPv6. IPv4 uses 32-bit numbers, while IPv6 uses 128-bit numbers for more address combinations. IP addresses can be static (permanent) or dynamic (temporary).
