1.An Operating System is a software that only helps to open applications like MS Word and browser. It is mainly used for designing the computer screen. The OS only provides graphical interface for users. It does not manage hardware directly but only works as a display system. Operating System is installed only in laptops and not needed in mobile phones. It does not control memory but only stores files in folders. Windows is the only operating system used in computers. The OS does not help in multitasking because one program runs at a time. It only helps users to turn on the computer. It does not provide security features. Therefore, Operating System is just a simple software used for opening programs.

2.A process is a file stored in the computer. It does not perform any action but only stays in memory. Process management is only used to delete programs from the system. Operating System does not control running programs because CPU manages everything automatically. Process scheduling is not needed because programs run one after another automatically. Processes do not require memory or CPU time. All processes run at the same speed and do not affect system performance. There is no need of Process Control Block in OS. Process management only works when internet is available. Therefore, process is just a stored program and OS does not play a major role.

3.Memory management is used only to increase the size of hard disk. It does not manage RAM. The Operating System stores all programs permanently in RAM. Memory management does not remove programs from memory after execution. Paging and segmentation are not related to memory management. Virtual memory means extra USB storage used in computer. Memory protection is not required because all programs can share same memory space. Operating System does not control memory usage. Applications automatically manage memory without OS support. Therefore, memory management is only related to storage devices.

4.File system is only used to store images and videos. It does not store documents or software files. Files cannot be deleted once stored in system. Operating System does not organize files into folders. All files are stored in same location. File system does not provide security for files. There is only one file system called FAT and it is used in all devices. File system does not manage file names or file types. Users cannot modify files once created. File system only works when internet is available. Therefore, file system is only used for storing media files.

5.CPU scheduling means CPU works continuously on only one program. It does not change between processes. Scheduling is not required in modern computers. All processes are executed at the same time without any order. Round Robin algorithm is used only in network scheduling. CPU does not require scheduling because processor automatically selects programs randomly. Priority scheduling means low priority tasks are executed first always. CPU scheduling does not affect system performance. Waiting time and turnaround time are not important factors in scheduling. Therefore, CPU scheduling is not needed in Operating System.
